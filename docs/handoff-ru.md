# Передача проекта для локальной работы

## Что уже есть

В репозитории сохранена точная постановка игры, двоичное сведение, строгие леммы об убывающих блоках, безопасный конечный обратный расчёт и список ошибок, которые нельзя повторять.

Главная нормальная форма:

\[
A(q)=\left\lceil\frac{3q}{2}\right\rceil,
\qquad
B(q)=R(A(q)),
\qquad B(q)<q,
\]

где `R` удаляет максимальный чередующийся хвост двоичной записи.

## Что пока не решено

Не доказано отсутствие ничейных позиций. Наличие у каждого игрока стратегии, принудительно завершающей партию, ещё не означает наличие выигрышной стратегии: такая завершающая стратегия может привести к победе соперника.

## Как начать работу в Кодексе

1. Открыть папку репозитория.
2. Дать Кодексу прочитать `AGENTS.md`.
3. Использовать задание из `CODEX_PROMPT.md`.
4. Сначала запустить тесты:

```bash
python -m unittest discover -s tests -v
python scripts/verify_claims.py --limit 100000
```

5. Просить Кодекс не увеличивать бездумно перебор, а искать структурное доказательство.

## Самые перспективные направления

- конечный двоичный автомат вместе с числовой функцией ранга;
- описание невозможного ядра ничейных позиций;
- обратные деревья для операций `A` и `B`;
- ранги для блоков ходов, а не для каждого отдельного хода;
- автоматический поиск контрпримеров к каждой новой лемме до попытки доказательства.

## Важное правило

Файл `docs/proof-ledger.md` — источник истины о статусе утверждений. Всё, что не отмечено как доказанное, нельзя выдавать за решение задачи.
