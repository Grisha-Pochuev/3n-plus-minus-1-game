# Article history

This directory preserves the manuscript as it changed over time:

`v1 → v2 → v3.0 → v4.0 → v5.0 → v6.3 → v7.0`

Each folder contains the LaTeX source and a PDF of that version.

Older versions are historical snapshots and may contain arguments that were corrected or withdrawn later. The current working manuscript remains `paper/main.tex` and `paper/main.pdf`.

Future versions should simply be added as a new folder, without rewriting the older ones.
